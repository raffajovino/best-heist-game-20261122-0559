**BLUEPRINT — The Halcyon Heist.** You are Wren, and you have the museum's blueprint. Cross three rooms in one night — the Grand Gallery, the Service Corridor, the Vault of Light — reading guard patrols and sweeping camera cones before you move, spending a handful of tools (a tossed coin, a smoke pellet, a camera loop) where the plan needs them, cracking the case for the Lumen Diamond, then getting out through the skylight before the alarm meter fills and the museum locks down.

The game is drawn as a blueprint: indigo paper, white line walls, dark cover, amber danger cones, gold loot — danger warm, safety dark, loot gold, readable at a glance. Vanilla Canvas 2D + WebAudio, zero dependencies, zero network requests.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```

WASD / arrows move · Shift sneak · Click throw · 1/2/3 tools · Space interact · P pause · R restart · M mute.

## Run it (the entry program)

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
